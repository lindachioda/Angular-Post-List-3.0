## 📝 Starting from the Starter Project Angular-Post-List-2.0
Angular Post & Users Management

Starting from the provided starter project, the application was modified and extended with the following features:

* Convert todos.service.ts into an Angular service and add an author: string field to the posts.
* Create a custom pipe to transform text into uppercase.
* Create a custom directive to highlight the text where it is applied, following the best practices covered during the lesson.
* Create a route for the post details page, displaying all the post fields.
* Create a /users route and a users service to retrieve the list of users and display the selected user's details on the same page.
* Redirect all non-existing routes to the home page.
